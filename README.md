# SWYNEX-Data-Cleaning-and-Basic-Analysis

This repository contains the deliverables for **Task 2 (Data Cleaning and Basic Analysis)** of the SWYNEX bioinformatics internship program [cite: 1].

## Dataset Overview
- **Dataset File:** `data_summary.tsv` [cite: 1]
- **Target Organism:** *Escherichia coli* str. K-12 substr. MG1655 [cite: 1]
- **Metrics Analyzed:** Assembly Accession, Source (GenBank vs. RefSeq), Genome Size, Contig N50, and Gene Count [cite: 1].

## Contents
- `Data Cleaning.ipynb`: Google Colab notebook featuring data loading, inspection, missing value handling, and summary statistics [cite: 1].
- `data_summary.tsv`: The raw dataset containing GenBank and RefSeq assembly summaries [cite: 1].
- `Bar_Plot.png`: Visualization comparing the total gene count across assembly sources [cite: 1].
